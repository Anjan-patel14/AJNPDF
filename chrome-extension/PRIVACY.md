# AJN PDF Quick Tools — extension privacy notes

The extension package requests no host permissions and no permissions to read browsing history, page content, passwords, cookies or open-tab content.

The four local quick actions receive only image files the user explicitly selects or drops into the extension workspace. The package contains no upload path for these local quick actions.

The extension can open ajnpdf.com pages chosen by the user. Once the website opens, AJN PDF website privacy and cookie policies apply to that website visit.

All extension runtime logic is bundled with the extension package. No remotely hosted JavaScript is executed.
