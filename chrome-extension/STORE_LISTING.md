# Chrome Web Store listing draft

## Name
AJN PDF Quick Tools

## Summary
Local image quick tools plus fast search across 100+ AJN PDF workflows. No page or browsing-history access.

## Category
Productivity

## Single purpose
Provide quick, user-initiated file preparation actions in Chrome and help the user find the matching AJN PDF workflow.

## Detailed description
AJN PDF Quick Tools puts a small set of useful file actions in Chrome without asking for page-reading or browsing-history permissions.

Included local quick actions:
- Combine selected images into a PDF.
- Reduce image file size using a selected quality level.
- Resize an image while preserving its aspect ratio.
- Convert an image to JPG, PNG or WEBP.

The popup also searches the AJN PDF public workflow catalog so you can open the right PDF, conversion, image, editing or security workflow without browsing a long directory.

The native quick actions use only files you explicitly select. Their processing logic is packaged with the extension. The extension does not contain content scripts or remotely hosted JavaScript.
