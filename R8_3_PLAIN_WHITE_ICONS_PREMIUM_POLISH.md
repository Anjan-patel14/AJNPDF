# AJN PDF 3.1.0 R8.3 - Plain White Icons / Premium Polish

R8.3 is a frontend-only refinement of the R8.2 premium workspace.

## Updated
- All 107 tool icon shells use a clean plain-white background with a subtle neutral border and soft shadow.
- Conversion format badges also use white surfaces; color is reserved for the glyph/accent rather than the icon background.
- Homepage category, format, workflow and safeguard icon tiles use the same white-surface treatment for a consistent product system.
- Existing unique tool glyph coverage is preserved: 34 dedicated action glyphs and 73 source-to-target conversion treatments.
- Old public-facing phrases such as browser-processing labels, temporary-processing labels, search-intent wording and developer-facing testimonial/badge wording are replaced with calmer user-facing copy while keeping all five locale key structures intact.
- Homepage FAQ and safeguard copy use simpler secure-processing wording.

## Preserved from R8.2
- Full-page processing animation without visible processing seconds.
- Share action after supported result flows.
- Mobile horizontal tool cards.
- Desktop 2x2, 4x4 and Horizontal layout selector with persistence.
- Subtle wave background and selective visual story panels.
- Light-only presentation and transparent AJN brand logo.
- Existing tool workflows, capability manifest, package files and backend behavior.

## Safety
The updater captures SHA-256 hashes from the repository's current Git-tracked backend before copying frontend files. Backend files, package.json, package-lock.json and src/generated/backend-capabilities.json are not copied or staged by this release.
