# AJN PDF 3.1.0 R8.2 - Premium UI/UX Polish

Frontend-only refinement of the R8 professional workspace.

## Card directory
- Removed processing-mode wording from tool cards.
- Mobile stays one horizontal card per row.
- Desktop defaults to a cleaner 2 x 2 layout.
- Users can switch between 2 x 2, 4 x 4 and Horizontal layouts.
- Layout preference is stored locally.
- Tool icons remain the 107-tool simple vector system.

## Processing experience
- Full-page document-processing experience remains active for supported server and local jobs.
- No visible processing timer or 0-second counter.
- File-sheet animation, scan line, progress rail and stage labels replace dot-only loading.
- Processing copy was rewritten to sound calmer and more user-facing.

## Results
- Download remains the primary result action.
- Share remains available after supported result flows.
- Process another remains available as the follow-up action.

## Homepage polish
- Smart / Fast / Effortless hero language retained.
- Technical or developer-facing marketing copy reduced.
- New selective visual-story panels illustrate page organization and conversion without copying another product.
- Wave-based background treatment retained; no decorative circle blobs were added.
- Format, workflow, FAQ and safeguards copy was simplified and polished.

## Safety
- Frontend only.
- backend/ is never copied or staged.
- package.json and package-lock.json are never replaced.
- Current Git-tracked backend files are hashed before frontend copy and verified again before commit and after build.
