# AJN PDF CRO Measurement Plan

## Primary funnel
Landing page → tool open → valid file selected → processing started → successful result → download.

## Diagnostic ratios

- Tool-open rate = tool opens / category or landing page views.
- Start rate = tool starts / tool page views.
- Success rate = successful outputs / tool starts.
- Download rate = downloads / successful outputs.
- Error rate = tool errors / tool starts.

## Improvement order

1. Fix broken or confusing processing before changing copy.
2. Improve file requirements and validation where start rate is low.
3. Improve progress, errors and retry where completion is low.
4. Improve result naming, preview and download visibility where download rate is low.
5. Test one meaningful UI change at a time and compare equivalent periods.
