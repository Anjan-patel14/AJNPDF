# AJN PDF Backlink and Authority Plan

## Linkable assets to publish

1. A transparent PDF conversion compatibility matrix with real sample files and output notes.
2. An  language test page covering English, Hindi, Telugu, Tamil, Kannada and Malayalam.
3. A PDF password and permissions explainer with reproducible Adobe Reader checks.
4. A browser-versus-server processing architecture diagram.
5. A public changelog documenting fixed converters, known limitations and removed claims.

## Outreach targets

- University resource pages and digital-library teams for  guidance.
- Small-business and office-productivity publications for workflow guides.
- Accessibility and archiving communities for searchable-document documentation.
- Open-source project lists where AJN PDF genuinely integrates or contributes.
- Relevant developer communities for the public API and conversion test methodology.

## Outreach rules

- Send a specific resource that helps the recipient's audience.
- Do not buy links or exchange links at scale.
- Do not create fake reviews, fake accounts or automated forum mentions.
- Keep anchor text natural and varied.
- Record outreach, response, acquired link, target page and referral traffic.
